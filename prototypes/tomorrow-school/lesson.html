Инструкция

Напиши функцию ForEach, которая для среза int применяет функцию к каждому его элементу.

Ожидаемая функция

func ForEach(f func(int), a []int) {

}

Использование

Пример программы, чтобы проверить функцию:

package main

import "piscine"

func main() {
	a := []int{1, 2, 3, 4, 5, 6}
	piscine.ForEach(piscine.PrintNbr, a)
}

И её вывод:
